**𝗬𝗨𝗞𝗜 𝗡𝗦𝗙𝗪 𝗔𝗣𝗜** is a high-speed, purely local AI image moderation server designed to detect explicit content instantly. Built with **FastAPI** and **NudeNet**, it runs entirely on CPU with ultra-low latency, making it perfect for Telegram bots and community moderation systems.

Control the strictness and server settings via `config.py` or Environment Variables:

```python
PORT = 7860
WORKERS = 2
NSFW_THRESHOLD = 0.01  # Lower = Stricter
STRICT_NSFW = {
    "ANUS_EXPOSED",
    "FEMALE_BREAST_EXPOSED",
    "BUTTOCKS_EXPOSED",
    "FEMALE_GENITALIA_EXPOSED",
    "MALE_GENITALIA_EXPOSED",
}
```
